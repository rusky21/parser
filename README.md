# 🎯 LeadHunter Pro — Автономный парсер карт, аудитор сайтов и лидогенератор

Автономный комбайн для веб-студий, digital-агентств и b2b-продаж. Парсит организации с **Яндекс.Карт** и **2ГИС**, проводит глубокий аудит их сайтов в реальном времени, выявляет технические боли (SSL, адаптивность, аналитика, CMS) и автоматически генерирует персонализированные скрипты для холодных звонков менеджеров.

---

## 🚀 Быстрый старт (Работает ВЕЗДЕ)

Приложение полностью автономно: **фронтенд уже собран**, поэтому для работы нужен **только Python** (или Docker). Node.js устанавливать **не требуется**!

### 🪟 1. На Windows (Один клик)
Просто запустите двойным кликом любой из батников:
- **`start.bat`** — главное интерактивное меню (Десктоп-окно / Браузер / Консольный CLI / Swagger)
- **`start_desktop.bat`** — прямой запуск в нативном десктопном окне без рамок браузера
- **`run_backend.bat`** — запуск чистого бэкенда (`http://127.0.0.1:8000`)

*Скрипт сам создаст виртуальное окружение `.venv`, установит библиотеки и скачает Chromium для Playwright.*

---

### 🐧 2. На Linux, macOS и WSL
Сделайте скрипт исполняемым и запустите:
```bash
chmod +x start.sh
./start.sh
```
*Скрипт автоматически определит систему, развернет `.venv`, установит зависимости и Chromium.*  
*На серверах без дисплея автоматически включится режим `HEADLESS=1`.*

---

### 🐳 3. Запуск в Docker (Любой сервер, VPS или облако)
Запуск одной командой без установки Python и браузеров на хост-машину:
```bash
docker compose up -d --build
```
После старта веб-интерфейс доступен по адресу:  
👉 **http://localhost:8000** (или по IP вашего сервера)

Для остановки:
```bash
docker compose down
```

## 🛠️ Ручной запуск через Python

Если вы предпочитаете ручное управление:
```bash
# 1. Создание и активация виртуального окружения
python -m venv .venv
source .venv/bin/activate       # Linux/macOS
# или: .venv\Scripts\activate   # Windows

# 2. Установка зависимостей
pip install -r requirements.txt
playwright install chromium

# 3. Запуск интерактивного меню или сервера
python launcher.py              # Интерактивное меню
# или: python run.py            # Напрямую сервер FastAPI
```

## 🌐 Порты и переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `8000` | Порт веб-сервера и API |
| `HOST` | `0.0.0.0` | Хост для биндинга uvicorn |
| `HEADLESS` | `auto` | `1` или `true` для работы парсера без открытия окна браузера (на серверах/VPS) |

## 💻 Разработка фронтенда (React + Vite + TailwindCSS)

Если вы хотите вносить изменения в интерфейс:
```bash
cd фронт
npm install
npm run dev     # Режим горячей разработки на http://localhost:5173
npm run build   # Сборка продакшн-бандла в фронт/dist
```
