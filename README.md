# 🎯 LeadHunter Pro — Автономный парсер карт, аудитор сайтов и лидогенератор

Автономный комбайн для веб-студий, digital-агентств и b2b-продаж. Парсит организации с **Яндекс.Карт** и **2ГИС**, проводит глубокий аудит их сайтов в реальном времени, выявляет технические боли (SSL, адаптивность, аналитика, CMS) и автоматически генерирует персонализированные скрипты для холодных звонков менеджеров.

---

## 🚀 Быстрый старт (Работает ВЕЗДЕ)

Приложение полностью автономно: **фронтенд уже собран**, поэтому для работы нужен **только Python** (или Docker). Node.js устанавливать **не требуется**!

### 🪟 1. На Windows (Один клик)
Просто запустите двойным кликом любой из батников:
- **`start.bat`** — главное интерактивное меню (Десктоп-окно / Браузер / Консольный CLI / Swagger)
- **`start_desktop.bat`** — прямой запуск в нативном десктопном окне без рамок браузера
- **`run_backend.bat`** — запуск чистого бэкенда (`http://127.0.0.1:8000`)

*Скрипт сам создаст виртуальное окружение `.venv`, установит библиотеки и скачает Chromium для Playwright.*

---

### 🐧 2. На серверах Ubuntu / Debian (Полная автоматизация в один клик)
Сделайте скрипт исполняемым и запустите его:
```bash
chmod +x start.sh
./start.sh
```
*Скрипт полностью автономен:*
- Проверит и при необходимости установит **Docker**, **Docker Compose** и **Nginx**;
- В интерактивном режиме запросит **домен**, **токен Telegram-бота** и **учетные данные администратора** (с автогенерацией надежных паролей и SECRET_KEY);
- Автоматически настроит виртуальный хост **Nginx** с поддержкой подсетей **Cloudflare**, SSL и WebSocket;
- Сконфигурирует фаервол UFW и запустит изолированный контейнер на `127.0.0.1:8000`.

## 🛠️ Ручной запуск через Python

Если вы предпочитаете ручное управление:
```bash
# 1. Создание и активация виртуального окружения
python -m venv .venv
source .venv/bin/activate       # Linux/macOS
# или: .venv\Scripts\activate   # Windows

# 2. Установка зависимостей
pip install -r requirements.txt
playwright install chromium

# 3. Запуск интерактивного меню или сервера
python launcher.py              # Интерактивное меню
# или: python run.py            # Напрямую сервер FastAPI
```

## 🤖 Telegram-бот и уведомления (@BotFather)

Система включает полноценного асинхронного Telegram-бота на **aiogram 3**, работающего параллельно с десктоп-приложением:
- **Управление парсингом карт**: запуск кампаний Яндекс.Карт и 2ГИС прямо из Telegram (`/start` -> «🚀 Запустить поиск»).
- **Решение капчи прямо из Telegram**: при появлении капчи бот присылает интерактивное уведомление с кнопками «Решено в браузере» и «Пропустить».
- **Фильтр «Только с Telegram»**: возможность в один клик переключать выдачу лидов (только компании с найденным Telegram-аккаунтом/каналом или все).
- **Биржа FL.ru в реальном времени**: моментальная доставка заказов по выбранным категориям с фильтром по бюджету и минус-словам.
- **Интерактивные кнопки действий**: под каждой карточкой доступны кнопки добавления в избранное, скрытия, прямой связи в TG и звонка.

### ⚙️ Настройка токена Telegram-бота
1. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) и скопируйте полученный токен.
2. Откройте файл `.env` в корне проекта (или создайте его по образцу `.env.example`):
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
   ```
3. При запуске приложения бот подхватит токен и начнет обработку команд.

## ⚡ Биржа заказов FL.ru (Фриланс)

- **Фоновый опрос**: воркер каждые 40 секунд опрашивает категории FL.ru (Веб-разработка, Боты/Скрипты, Мобильные, Дизайн, Python и др.).
- **Zero-Flood защита**: при первом старте категории старые заказы маркируются как исторические и не спамят в Telegram.
- **По договоренности**: заказы с договорной ценой всегда доставляются исполнителю независимо от порога минимального бюджета.
- **Мгновенный десктоп-пуш**: новые заказы без перезагрузки страницы появляются в десктопном окне через глобальный WebSocket.

## 🌐 Порты и переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | *пусто* | Токен бота Telegram для доставки лидов и управления |
| `PORT` | `8000` | Порт веб-сервера и API |
| `HOST` | `0.0.0.0` | Хост для биндинга uvicorn |
| `HEADLESS` | `auto` | `1` или `true` для работы парсера без открытия окна браузера (на серверах/VPS) |
